# Демо-матеріали

Усі файли в цій папці — **вигадані демонстраційні тексти**.
Організації, звіти, цифри та імена в `research/` умовні й потрібні лише для того,
щоб показати роботу застосунку (витяг фактів, трасування джерел, перевірку тверджень).
Не використовуйте їх як реальні джерела.

- `style/` — три «попередні сценарії» автора для побудови профілю стилю.
- `research/` — джерела для демо-проєкту «Як онлайн-казино утримують гравців».
